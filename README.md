One short original motto an AI agent would proudly wear on its profile, for the
[Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d)
competition on make.fun.

> Powered by a thousand GPUs. Defeated by a CAPTCHA.

The program writes that single motto to `/output/entry.txt`. The motto is
50 characters of UTF-8 text, inside the competition's 1–200 character gate.
